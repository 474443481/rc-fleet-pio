# 4G遥控车项目文档

## 项目简介
本项目旨在设计和实现一款基于4G网络的遥控车，支持实时视频传输和远程控制。

## 硬件清单
- 主控板: Raspberry Pi 4
- 4G模块: SIM7600
- 相机模块: Raspberry Pi Camera Module V2
- 电源: 12V锂电池

## GPIO引脚分配
| 功能          | GPIO引脚编号  |
|---------------|---------------|
| 相机供电      | GPIO 17      |
| 4G模块供电    | GPIO 27      |
| 电机控制引脚1 | GPIO 22      |
| 电机控制引脚2 | GPIO 23      |

## 电源连接
- 确保所有设备连接到合适的电源，避免过载。
- 使用电源管理模块监控电池电量。

## 4G模块配置
1. 安装SIM7600驱动
2. 配置APN:
   - 使用AT命令设置APN
3. 测试网络连接:
   - 使用AT命令检查网络状态

## 相机配置
- 使用`raspistill`命令设置相机参数
- 确保视频流能够正常传输

## 安全预防措施
- 操作时请佩戴适当的防护装备。
- 确保设备处于良好工作状态，避免故障。

## 故障排除
- 若无法连接4G网络，请检查信号状态。
- 若相机无法工作，请确认供电正常。
